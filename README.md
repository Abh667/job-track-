# Job Tracker

A Django-based web application to help users organize and manage their job applications in one place.

## Overview

The Job Tracker project is built using Python and Django. Its goal is to make job application management easier and more organized.

## Technologies Used

* Python
* Django
* SQLite
* HTML and CSS (if used in the project)

## Features

* Manage job application information
* Organize job-related records
* Store application data using a database
* Django-based backend

## Project Setup

### 1. Clone the repository

```bash
git clone https://github.com/Abh667/job-track-.git
cd job-track-
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate the virtual environment

Windows:

```bash
venv\Scripts\activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Run database migrations

```bash
python manage.py migrate
```

### 6. Start the development server

```bash
python manage.py runserver
```

Open this URL in your browser:

http://127.0.0.1:8000/
